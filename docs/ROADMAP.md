# Tasklist 开发计划（Roadmap）

> 本文档记录项目的开发计划、阶段进度与排期事项。设计细节见 [DESIGN.md](../DESIGN.md)。

## 已完成阶段

1. 脚手架：Vite + Vue 3 + TS
2. 数据层：类型定义、Pinia store、localStorage 读写（防抖）
3. 布局：左侧栏 / 右侧栏 / 主区，响应式（窄屏覆盖式）
4. 递归渲染：事项与组合的列表、状态计算、分组与排序
5. 新建 / 编辑 / 删除弹窗（Esc / Enter / 点遮罩）
6. 完成状态切换
7. 拖拽（位移阈值 + 半透明预览 + 无效目标还原）
8. 设置弹窗、i18n、浅/深主题、字号
9. 导入 / 导出（同 ID 覆盖合并）
10. PWA（manifest + SW）
11. 欢迎列表默认数据

## 规划中（未排期）

### 自绘日期/时间选择器（方案 B / C）

- **目标**：替换原生 `<input type="date">` / `<input type="time">` 的弹层，统一视觉（原生弹层为浏览器进程内 UI，无法样式化）
- **方案 B**：自绘日期选择器——日历弹层组件，复用现有设计 token，支持年/月切换、今天高亮、点击选择
- **方案 C**：自绘时间选择器——下拉列表或步进选择，成本约为 B 的一半
- **优先级**：B 先行（最影响观感），C 后续；B+C 全做视需要而定
- **实施流程**：先 brainstorming 敲定交互设计，再 writing-plans 出实施计划
